# Foreman3 Static HTML Replica

## Completed
- Created complete `index.html` (112KB) — faithful static replica of React+Vite+Tailwind construction app
- Created `js/script.js` (45KB) — all interactive behavior

## Sections Included
1. **Navigation** — Sticky nav with Logo, desktop links, Start Free Trial, mobile hamburger + dropdown
2. **Hero** — Scanlines, hero-bg.jpg, gradient overlays, glowing orbs, badges, CTA buttons, orbit rings, HUD stat panels (98.4%, 1.2 SECS)
3. **BlueprintTakeoff** — Trade switcher (electrical/plumbing/hvac), 3 tool buttons per trade, SVG floorplan canvas, zoom controls, watermark, upload + clear buttons
4. **EstimatorPanel** — Itemized Scope + Live Compiler badge, client/project inputs, compiled materials/manual items, add manual form, Labor Rates sliders, Valuation Terminal with markup/tax, grand total, proposal modal
5. **ProcurementHUD** — Supplier Linkages header, CREW NETWORK ACTIVE badge, search, filter buttons (all/electrical/plumbing/hvac), supplier cards rendered by JS
6. **Features Bento** — 3-cell bento grid with blueprint-bento.jpg, trade-linkages.jpg, waste stats
7. **Three-Step Section** — Splite before/after slider, 3 sticky glass-panel cards (01/02/03)
8. **Trade Pillars** — 4 cards (Site Resistant, Offline Core Sync, Deep Code Logic, Profit Protection) with gradient top bands
9. **Pricing** — Billing toggle (monthly/annually), 3 tiers (Solo $79/63, Crew $149/119, Fleet $299/239) with feature lists
10. **ContactForm** — Initialize Connection, name/email, package select, billing toggle, message textarea, math captcha, progress logs console, success state
11. **3D Spline Scene** — SPATIAL COMPUTING TWIN, left sidebar (Spawner/Inspector tabs), 6 equipment types, 4x4 grid board, HUD display, tool buttons (orbit/pan/auto), layer buttons, zoom, quote modal with BOM
12. **Footer** — Back-to-top button, 4-column grid with logo + social links (LinkedIn, YouTube, Facebook, Instagram), workspace tools, legal links
13. **Legal Pages** — Hidden divs for Terms of Service, Privacy Policy, Procurement Policy with full content
